# 拾见校园：失物招领小程序交互原型

[在线体验原型](https://grim761.github.io/campus-lost-found-prototype/) · [九页原型总览](storyboard.png) · [使用流程图](flowchart.png)

本项目展示校园失物招领小程序的需求分析原型，包含首页、搜索、搜索结果、信息详情、领取方式、发布、发布成功、我的发布和状态更新九个页面。可体验浏览、搜索、发布和修改状态。

原型使用 [Slicerflow](https://slicerflow.live/prototype/) 设计；[Slicerflow YAML 源文件](拾见校园.slicerflow.yaml)可在工具的 Code 标签中导入查看。在线交互页仅使用演示数据，不保存或提交真实信息。
